# hmcts-developer-challenge
HMCTS requires a new system to be developed so caseworkers can keep track of their tasks. Your technical test is to develop that new system so caseworkers can efficiently manage their tasks.

# HMCTS Developer Challenge

This project is a full-stack application for the HMCTS developer challenge. It includes a backend service and a frontend interface built for a government service experience.

## GOV.UK controls

This project uses GOV.UK styles and controls, following the GOV.UK design system conventions for accessible, consistent government service interfaces.

## Getting started

- Backend: see the backend README for setup and running instructions.
- Frontend: see the frontend README for the UI setup and local development commands.

## Technology overview

- Java/Spring Boot backend
- Node.js/TypeScript frontend
- GOV.UK design patterns and UI controls
